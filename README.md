# 🚴 Bike Sales Dashboard | Microsoft Excel

## 📌 Project Overview

The Bike Sales Dashboard is an interactive Excel dashboard designed to analyze customer purchasing behavior and identify the key factors influencing bike purchases. The project transforms raw sales data into meaningful business insights using data cleaning, Pivot Tables, Pivot Charts, Slicers, and dashboard design techniques.

This dashboard enables users to explore customer demographics, income distribution, commute distance, and purchasing trends to support data-driven business decisions.

---

## 🎯 Business Objective

To analyze customer purchasing patterns and identify factors affecting bike purchases based on demographic and lifestyle attributes.

---

## 📊 Dashboard Features

- 📈 Average Income Analysis
- 👨‍👩‍👧 Customer Age Brackets
- 🚴 Bike Purchase Analysis
- 🚗 Commute Distance Analysis
- 🌍 Regional Sales Distribution
- 🎓 Education-wise Analysis
- 👨 Gender-wise Analysis
- 🎛 Interactive Slicers

## 📂 Dataset

The dataset contains customer information, including:

- Gender
- Age
- Income
- Education
- Occupation
- Region
- Marital Status
- Commute Distance
- Purchased Bike

---

## 📈 Key Business Insights

- Customers with higher annual income are more likely to purchase bikes.
- Middle-aged customers represent the highest number of bike purchases.
- Commute distance influences purchasing decisions.
- Purchasing behavior varies across different regions.
- Customer demographics significantly impact bike sales.
